# prabalbarahi.com.np

My personal website — built with plain HTML/CSS/JS, no frameworks.

🔗 **Live site:** [prabalbarahi.com.np](https://prabalbarahi.com.np)

## About

A personal site to showcase who I am and the projects I'm working on, with a
circuit-board/breadboard visual theme tying together my background in
Electrical Engineering and my growing interest in software development.

## Structure

- `index.html` — main site (About, Projects, Resume, Contact)
- `favicon.png` — site icon
- `*.pdf` — project reports and resume
- `CNAME` — custom domain configuration for GitHub Pages

## Built with

- HTML5, CSS3, vanilla JavaScript
- Hosted on GitHub Pages
- Custom `.com.np` domain via Cloudflare DNS
